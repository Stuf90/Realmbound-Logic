## KEYWORD GLOSSARY (P13)

| KEYWORD | MEAN |
| --- | --- |
| ROW | CHARACTER SIT THIS ROW |
| COLUMN | CHARACTER SIT THIS COLUMN |
| Nth COLUMN, LITERAL NUMBER | CHARACTER SIT EXACT NUMBER COLUMN (FIXED, BOARD-WIDE) |
| UNDER (A) | LOWER ROW THAN A, **NOT NEED** SAME ROOM |
| ABOVE (A) *(INFER)* | HIGHER ROW THAN A, **NOT NEED** SAME ROOM — NOT OWN GLOSSARY CARD P13 SCAN (ONLY "UNDER" SHOW), BUT WORD ITSELF USE DIRECT CASE 38 OFFSET CLUE — SYMMETRIC OPPOSITE "UNDER", SAME LOGIC FLIP DIRECTION. TREAT AS REAL KEYWORD, JUST MISS OWN CARD IN OUR PHOTO SET (OR BOOK NEVER GIVE OWN CARD, ASSUME OBVIOUS FROM "UNDER"). |
| LEFT OF (A) / RIGHT OF (A) | SAME ROW, STRICT LESS/GREATER COLUMN THAN A |
| BESIDE | DIRECT UP/DOWN/LEFT/RIGHT **AND** SAME ROOM |
| NOT BESIDE (CHARACTER) *(DERIVE, ENGINE)* | NEGATE "BESIDE" — ANY PLACEMENT NOT BOTH ADJACENT + SAME-CHAMBER. NO OWN GLOSSARY CARD (BOOK "NAAST" COVER BOTH SENSE), BUT ENGINE HAVE SEPARATE `not-beside` PREDICATE |
| NOT BESIDE A WALL *(DERIVE, CASE 4)* | CELL FULL INTERIOR ROOM, TOUCH NO WALL ANY SIDE — NOT OWN GLOSSARY CARD, BUT DIRECT CLUE PHRASE CASE 4 |
| CORNER | CELL WHERE TWO WALL SAME ROOM MEET |
| ONE OF THE FOUR CORNER *(DERIVE, CASE 76)* | DISJUNCTIVE VARIANT "CORNER" — MATCH **ANY** FOUR CORNER CELL, NOT ONE FIX CELL |
| BY A WINDOW | CELL TOUCH WINDOW (EDGE-ONLY PROP, SPAN TWO CELL) |
| ALONE | NOBODY ELSE ROOM, NOT EVEN VICTIM |
| ALONE WITH (B) | ONLY THESE TWO PEOPLE ROOM |
| NOT ALONE *(DERIVE, CASE 76)* | NEGATE "ALONE" — AT LEAST ONE OTHER SHARE ROOM |
| ALONE ON [PROP AREA] *(DERIVE, CASE 38)* | "ALONE" LOCALIZE TO PROP-TAG AREA (E.G. "STAND"), NOT WHOLE ROOM |
| EMPTY | NOBODY ROOM AT ALL, NOT EVEN VICTIM |
| NO EMPTY ROOM *(DERIVE, CASE 39)* | GLOBAL, BOARD-WIDE — NEGATE "EMPTY" ACROSS **EVERY** ROOM AT ONCE, NOT ONE NAME ROOM |
| ONLY PERSON ON [PROP] | NOBODY ELSE SIT SAME PROP TYPE, NOT EVEN VICTIM (CHAIR, RUG, TABLE-ADJACENT, ETC.) |
| EXACTLY ONE PERSON ON [PROP-KIND] *(DERIVE, CASE 76)* | GLOBAL UNIQUE QUANTIFIER, CAST-WIDE, SCOPE WHOLE PROP-KIND (E.G. "CHAIR") NOT SINGLE PROP CELL — BIGGEST DEPART FROM "ONLY PERSON ON [PROP]" (THAT ONE STILL PER-PROP-CELL SCOPE) |
| ROOM/CHAMBER | ANY ENCLOSE AREA — INCLUDE ALLEY, JACUZZI, ETC. |
| TWO PEOPLE STOOD BESIDE A TABLE | EXACT TWO PEOPLE ADJACENT SAME TABLE, VICTIM MAY BE ONE OF TWO |
| BESIDE THE SAME [PROP] *(DERIVE, CASE 39)* | EXISTENTIAL PAIR — NAME CHARACTER BESIDE PROP, **SECOND** CHARACTER ALSO BESIDE SAME PROP STAY UNNAME |
| ROOM WITH EXACTLY N OTHER SUSPECT *(DERIVE, CASE 54)* | ROOM OCCUPANT-COUNT, EXACT NUMBER, EXCLUDE SELF |
| NO [CATEGORY] BESIDE [PROP] *(DERIVE, CASE 54)* | GLOBAL — NOBODY MATCH CATEGORY (E.G. GENDER) ADJACENT NAME PROP, ANYWHERE BOARD |
| SAME DIAGONAL AS (A) (OR (B)) *(DERIVE, CASE 38)* | ONE ROW **+** ONE COLUMN APART FROM REFERENCE; DISJUNCTIVE VARIANT ALLOW **OR** OF TWO REFERENCE CHARACTER |
| N COLUMN AND M ROW LEFT/RIGHT ABOVE/UNDER (A) *(DERIVE, CASE 38, 76)* | RELATIVE OFFSET — EXACT VECTOR DISTANCE BOTH AXIS, STRONGER THAN PLAIN UNDER/ABOVE/LEFT/RIGHT (DIRECTION ONLY) |

## PATTERN GROUP (ROUGH, PRE-DIFFICULTY)

GROUP #1-43 ABOVE INTO ROUGH SHAPE FAMILY, HELP NEXT STEP (DIFFICULTY ASSIGN) SORT
FASTER. **NOT FINAL** — JUST SORT AID:

1. **POSITION FACT, SINGLE CHARACTER** — ROW, COLUMN (INCLUDE LITERAL NUMBER + "LAST"/
   "BOTTOM" EDGE PHRASE), NAME-ROOM, CORNER, BY-WINDOW, BESIDE-PROP (NAME + NEGATE),
   OCCUPY-PROP (NAME + NEGATE + DISJUNCTIVE OR), NOT-BESIDE-WALL.
2. **RELATION, TWO CHARACTER** — UNDER/LEFT/RIGHT (RELATIVE DIRECTION), DIAGONAL (INCLUDE
   DISJUNCTIVE OR), RELATIVE OFFSET (EXACT VECTOR DISTANCE), NOT-BESIDE(CHARACTER).
3. **ROOM-LEVEL FACT** — ALONE, ALONE-WITH(B), NOT-ALONE, EMPTY, OCCUPANT-COUNT (EXACT
   N OTHER), ALONE-ON-PROP-AREA (LOCALIZE ALONE TO PROP TAG).
4. **PROP-LINK, UNNAME SECOND PARTY** — BESIDE-SAME-PROP (EXISTENTIAL PAIR), TWO-PEOPLE-
   BESIDE-TABLE (EXACT COUNT PAIR), PROP-IN-CHARACTER-COLUMN (PROP-TO-COORDINATE LINK).
5. **GLOBAL / CAST-WIDE** — NO-EMPTY-ROOM, CATEGORY-EXCLUDE-FROM-PROP (GENDER ETC.),
   GLOBAL-UNIQUE-QUANTIFIER (EXACT N CAST-WIDE ON PROP-KIND).
6. **COMPOUND (STACK TWO+ FACT ONE CARD)** — SEE #10, #13, #17, #22, #26, #30, #36, #38,
   #39, #40, #42 — EVERY GROUP 1-5 FACT CAN STACK WITH ANOTHER SAME CARD. TREAT AS
   COMBINE, NOT NEW PRIMITIVE — CATALOG PRIMITIVE ONLY, COMPOUND = AUTHOR CHOICE LAYER
   ON TOP.
7. **VICTIM-SPECIFIC** — LAST-REMAIN-CELL (POSITION NEVER NAME DIRECT), ALONE-WITH-
   MURDERER (TRAITOR RULE, EVERY CASE STANDARD FOOTER, NOT A CLUE PREDICATE AT ALL).
